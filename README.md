# Я вертел Данила Маслова

**Шуточный сайт.** Никакого отношения к реальным событиям, конфликтам и личностям он не имеет: это шутка ради смеха, сделанная по просьбе. Если текст задел кого-то лично — это не было целью, напишите, и страница будет удалена.

Что внутри: одна страница, вращающийся 3D-куб из фотографий и большая надпись.

- `index.html` — весь сайт (HTML + CSS + JS в одном файле, без зависимостей)
- `danil_maslov.jpg` — фото для граней куба

## Локальный запуск

Открыть `index.html` двойным кликом. Ничего собирать не нужно.

## Свои фото

В конце `index.html` есть список:

```js
const photos = ['danil_maslov.jpg'];
```

Положите картинки рядом с файлом и перечислите имена — они распределятся по шести граням. Пока картинки нет, грань показывает заглушку «ДМ».

## Лицензия

Код — делайте что хотите. Фото принадлежит его владельцу и выложено только для этой шутки.
